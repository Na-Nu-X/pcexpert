# PC Expert Webpage Source Code

## English (EN)

### Used Technologies
This Web Page Is Build With Classic Front-End Client Technologies Such As **HTML**, **CSS**, **JS**. For Styles **SCSS** Is Included. For Back-End Server Side Is Used **PHP**. In Development Was Also Used **Git** To Improve Production.

### About Project
I Started Working On This Project To Learn Basics Of Web Development. At The Beginning I Didn't Even Know What Is HTML And How Web Pages Work. But One Day I Decided To Invest Time To Learn HTML And CSS From YouTube Tutorials. Then I Learned Basics Of JavaScript Programming Language. I Had To Move Up, So I Start Working With SCSS Styles. This Was Only A Front-End Part And For Back-End I Choosed PHP Programming Language. I Also Started Using Git To Save My Changes To Separate Commits.
